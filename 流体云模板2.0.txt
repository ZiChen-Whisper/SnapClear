流体云模板
流体云模板2.0
概述
从API2.0 (ColorOS14.0)开始，泛在服务框架支持流体云开发，流体云作为泛在服务的一种的展现形式。
OPPO 提供多种卡片模板，开发者通过填充数据接入后，便可让服务在流体云的多入口展现。

流体云的工程结构和普通卡片结构一致，需要在oml文件内声明流体云模板，如下：

<!-- xxx.oml -->
<template>
  <card-template entry="notification" category="模板分类">
       <!-- 模板内容 -->
  </card-template>
</template>
模板分类
流体云模板支持绑定变量和点击事件，但是不允许开发者修改样式，不支持使用CSS修改布局和样式。
目前流体云的模板清单如下：

category	描述
modular	组合模板
general	通用模板
symmetry	对称模板
media	音乐模板
组合模板
说明：
从API 3.0.0开始支持。如后续版本有新增内容，则单独标记该内容的初始支持版本。

image.png

流体云组合模板包含两种形态，胶囊态(含气泡态)和展开态，每种形态包含不同的区域，开发者可以在这些区域里填充信息，每个区域的填充规则不同，详见后续介绍。

1、组合模板由“顶部信息”+“核心信息”+“底部信息”组合而成，默认展示“核心信息”，可对单个模块的信息进行编辑；
2、业务可依据实际场景对三块信息进行任意组合，除了“核心信息”可单独显示，其它两者不可单独使用；
3、若仅需要“顶部信息”和“底部信息”时，“核心信息”可为非必选项；
4、若业务设计状态栏的卡为彩卡（黑色背景卡属于彩卡），则锁屏、通知中心均使用相同质感及颜色的彩卡，不区分亮暗模式；若业务未设计彩卡，则使用流体云1.0的亮色模式卡和暗色模式卡，锁屏、通知中心的流体云卡片均保持一致，需区分亮暗模式；
5、允许在状态栏黑色卡片背景的增加动态的背景图；
6、彩色卡片需要有描边处理，描边支持自定义颜色；

1.3、使用规范

1.3.1、胶囊态

推荐业务场景实例图
image.png

image.png

1、胶囊左侧和右侧必须各有一个元素（锁头场景除外，允许左侧显示一个），保证视觉平衡，信息状态长度变化时可移动元素位置保证配重；
2、胶囊单侧不可以有相同的元素，若业务未设计具体位置的，默认左边一个为[A]，右边为[B]；音频胶囊的右侧可为[D2*]；单个图标和文字元素之间支持自动转化；
3、在同一应用下，在信息发生扭转时，胶囊样式不支持样式变化
4、[A]、 [A0] 为服务图标/场景图标，包含图片/图标/动图/小组件类型，[B]、 [B0] 为文本信息，元素左右两侧展现不做具体限制可任意组合，信息可以随不同状态发生变化；
5、业务在设计时要保证流体云 1.0 胶囊中的[A]、[B]数据信息在 2.0 中体现（过长的文本信息须精简），若在 2.0 上未设计[A]、 [A0] 时，1.0胶囊中的[A]将会使用默认的服务图标【A1*】，
6、若流体云 1.0 上的超长文本信息，在 2.0 设计上使用需要精简至范围内（最多5个字符），若未精简的文本信息直接兼容至 2.0 时，胶囊拉伸变长，优先信息显示完整，若达到胶囊最大宽度后，以“…”形式显示；
7、若 2.0 中使用的非等边的图形，回落至 1.0 中可使用原有的[A]（已有1.0流体云）或 [A1*]服务图标（新业务）；若 2.0 中使用的圆角矩形，在 1.0 中则需自动裁切成圆形；
8、胶囊背景为黑色，不允许开发者自定义。
9、图形元素需使用透明无色背景 ，若业务有特殊场景需求，图形元素的大小或形状可根据业务场景设计

兼容性

1、为保障流体云 2.0 与 1.0 的兼容性，业务在设计或开发时必须提供 [A1*] 服务图标，[A1*] 可以不在胶囊或卡片的前端中显示。
2、同一实时活动下，在状态发生变化，信息扭转时，胶囊样式不支持样式变化；
3、当为非居中挖孔时，气泡居中状态栏显示，不论是单个胶囊还是胶囊组都显示“月牙”，在气泡中显示图标，图标依次从[A]→[A0]获取，需判断[A]是否为方形，是方形则正常使用；若不是方形，再判断[A0]；若[A0]也非方形，则显示[A1*]应用图标兜底；若胶囊中无[A]/[A0]时，则显示[A1*]；
4、若[A]/[A0]为图片，变为防烧屏气泡时，需把[A]/[A0]图片裁切成圆形；若[A]/[A0]为动图或小组件时则显示 [A1*] 信息。

1.3.2.2、展开态容器 - 核心信息
image.png

1、核心信息默认组合模板分为：图形区、信息区、操作区，信息区为必显，图形区和操作区可根据实际场景隐藏；
2、图形区：主要显示图形，图形大小不支持变动，可隐藏
3、信息区：主要有核心文本、辅助文本、标签组合而成，最多可三行；
4、操作区：主要有按钮、图片，二者仅可使用一个；

image.png

1、[D] 为图片信息，当有 [D] 信息时，不可显示 [E]组按钮；若业务不需要右侧按钮或图片时，右侧信息可为非必选项，但左侧至少有2项元素；
2、按钮 [E] 支持文本按钮和图形按钮，开发者只能选用其中一种，图形按钮最多支持显示 3 个；若有 [E3] 按钮时，不可有[D1] 元素，[B1]自适应变长 ；
3、[C1] 信息须简短，当文字过长时，跑马灯显示，跑一次后截断；[B1*]为核心文本信息，文本字号、字重支持变化；
4、[C2]/[C3] 信息的字段允许获取多个接口信息，最多2个，中间可以用符号隔开，如：“·”、“|”、“空格”；
5、[G1]/[G2]/ [G3]/[G4]为标签， [G1]与[G2]、[G3]与[G4]两者互斥，仅可使用一个；
6、标签由图标（[D2]/[D3]/[D4]/[D5]) + 文本([C4]/[C5]/[C6]/[C7]) + 背景([F2]/[F3]/[F4]/[F5]) 组合构成，标签组合显示时，必须要有背景；文本单独显示时，必须要有背景；图标单独显示，可以不要背景；标签必须与[C2]/[C3] 搭配使用；
7、标签可以不显示，也可以跟随文本整行不显示；
8、文本按钮【E4】和图形按钮【E1*】混合使用时，最多只能使用一个图形按钮和一个文本按钮；
9、混合使用时，文本按钮【E4】放置图形按钮左侧或右侧均可；
10、若文本按钮【E4】放置最右侧时，【E4】可替换【E1*】，与【E2】混合使用，若未配置【E2】时，【E3】移至【E2】位置；
11、注意：各业务在设计文本按钮与图形按钮混合使用时，需保证文本按钮在各语种下的可视性，若文本按钮可视性差，建议隐藏【D1】元素
12、[D1] 支持圆形和圆角方形的单独图形
13、小组件按钮同时最多可使用2个，可单独使用也可与图形（圆形）按钮混合使用；混合使用时最多显示3个按钮（含小组件按钮）；
14、当小组件按钮和图形（圆形）按钮混合使用时，小组件按钮可直接替换原有图形（圆形）按钮的位置；
15、不支持中途切换图形（圆形）按钮和小组件按钮

概述

流体云的工程结构和普通卡片结构一致，需要在oml文件内声明流体云模板，如下：

<!-- xxx.oml -->
<template>

音乐模板


1、“*”表示为必选信息，无“*”为可选信息；

2、[A*]、[B*] 主要用于状态栏胶囊/气泡的展示，[A1*]、[B1*] 用于其他触点的展示，两组信息相互独立；

3、整体布局由[ G1显示区域 ] + [ G2操作区域 ] 两部分构成，G1显示区域数据为自动获取；

4、[ D1* ]可为动图或图片，主要获取专辑图片，当未获取时显示音乐占位图，胶囊也同步展示位占位图；

5、[ D2* ] 信息为ICON展示区域，可为动图或图片，[ A1* ] 主要展示应用品牌；

6、[ D3* ] [ C2* ] [ C3* ] 区域为播放时间及播放进度显示，滑动/点击可调整播放进度；播放进度长按是高度发生变化；

7、[ E ]为图形按钮， 建议使用简单易懂的图形按钮，避免使用表意模糊的图形按钮，[ E1* ] [E2* ] [E3* ] 为主操作按钮，[ E4* ]为媒介图标 ，可根据连接的播放介质不同而变化图，[ E5 ]为操作补充位非必显，便于后期扩展。

8、[ F ] [ F1 ]胶囊/卡片背景为高斯模糊，不允许开发者自定义；
