流体云组件
针对流体云模板，只能使用特定的几种类型的组件，每个模板支持的组件类型略有不同。

组件通用
条件渲染

if 渲染指令指 if | else 控制指令，用于控制是否添加或移除某个组件，使用{{ }}和条件绑定，只有当条件为 true 时，组件才会被添加，条件为 false 时，组件会被移除。

示例：

  <text level="1:B*" if="{{ showText }}">{{ description }}</text>
  <image level="1:B*" src="{{ logo }}" else></image>
注意：除了G1, G2信息外，绑定if else的两个对应的组件level必须一致。

说明：
从API 3.0.0开始支持。如后续版本有新增内容，则单独标记该内容的初始支持版本。

线性渐变
为了创建一个线性渐变，你必须至少定义两种颜色节点。颜色节点即你想要呈现平稳过渡的颜色。同时，你也可以设置一个起点和一个方向（或一个角度）。向下/向上/向左/向右/对角方向

渐变通用属性：
过渡方向
通过angle指定方向

bg-color="linear-gradient(angle, color1, color2, color3,...)"
过渡方向
至少配置两种颜色
参数：

名称	类型	默认值	必填	描述
angle		180deg	否	过渡方向，以元素几何中心为坐标原点，水平方向为X轴，angle指定了渐变线与Y轴的夹角(顺时针方向)。注：angle角度是45的整数倍，范围[0,360）
color		-	是	定义使用渐变样式区域内颜色的渐变效果。注：不支持颜色值后面配置百分比
示例：
默认渐变从上到下

<expanded bg-color="linear-gradient(#FF7043,#15d5db)" level="F1*" >        
</expanded>
image.png

渐变从左到右

<expanded bg-color="linear-gradient(90deg,#3D43EB,rgb(255, 112, 67))" level="F1*" >        
</expanded>
image.png

说明：
从API 2.1.0开始支持。如后续版本有新增内容，则单独标记该内容的初始支持版本。


概述
滑动容器，提供切换子组件显示的能力, 仅音乐模板在锁屏入口支持。


属性

名称	类型	默认值	必填	描述
index	number	0	否	当前在容器中显示的子组件的索引值, 可以绑定变量。
样式

不支持自定义样式。


子组件

支持。


事件

名称	参数	描述
click	-	点击动作触发该事件, 通过在组件上添加onclick="xxx"来绑定事件
change	{index:currentIndex}	滑动切换时会触发该事件， 通过在组件上添加onchange="xxx"来绑定事件

方法

不支持。


示例

<swiper for="{{ data }}" index="{{ index }}" onclick="clickSwiper" onchange="{{ swiperChange }}">
   <text level="2-1:C1"> {{ $item.content }}</text>
</swiper>

      "params": {
        "index": "{{ index }}"
      }
     },
     "swiperChange": {
       "params": {
         "index": {{ index }} 
       }
     }
  }
}
</data>
